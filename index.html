02 — 版式

八种版式，
各有各的语气。

同一段文字，可以素净，可以锋利，也可以像一页旧书。生成后随时切换，图片会重新绘制。

格物支持高亮、下划线与行号开关；电光会把开头一句放大成标题。

03 — 细节

为「留下来」做的细节。

不是把文字截成图，而是让这张图值得被保存、被找到、被再次打开。

3× 高清 PNG

普通卡片优先以 3 倍尺寸输出，文字边缘更干净。长文按安全尺寸依次降到 2×、1.5×。

16384 px 单边上限 · 约 16 MP 总量

本地卡片库

生成后自动保存到 IndexedDB。搜索、收藏、批注、打标签，不引入账号和服务器。

starscard-library · 数据只在本机

ZIP 备份与恢复

把文字与图片一起导出，导入时逐张校验、去重。换电脑前，先给自己留一份备份。

JSON 元数据 + 独立图片

原文二维码

每张卡片都带着原文链接。小红书等页面的签名与业务参数会保留，扫码能回去。

高分辨率源图 · 关闭绘制平滑

长文不慌

超出安全画布时停止绘图，但完整原文仍在。可以复制文字、换版式，或降低倍率重试。

原文优先 · 不丢选区

隐私默认

04 — 卡片库

读过的句子，
不该散落在截图里。

每次生成都会自动存进本地卡片库。搜索、收藏、打标签、写批注，需要时再找回来。

  • 自动保存：生成成功后写入浏览器 IndexedDB，可随时关闭。
  • 找得回来：按标题、来源、标签筛选，支持「未整理」视图。
  • 写得下去：每张卡片独立批注与标签，编辑区默认折叠不打扰。
  • 带得走：ZIP 备份包含文字与图片，导入逐张校验、去重。

05 — 隐私

没有账号，没有云端，
没有偷偷上传。

01

本地处理

摘录、标题、链接、生成的图片，都在你的浏览器里完成。开发者服务器不会收到这些内容。

02

最小权限

只申请 clipboardWrite、scripting、storage 三项权限；访问范围仅限 http/https，且只在你划词后读取选区。

03

你说了算

自动保存可以关闭，卡片库可以清空，备份文件只留在你选择的位置。没有云端同步，也没有隐藏账号。

摘星卡片是免费的吗？

免费。不需要注册账号，也没有订阅或内购。安装后即可使用全部版式和本地卡片库。

我的摘录会被上传吗？

不会。摘录、页面标题、链接和生成的图片都在浏览器本地处理。开发者没有接收这些内容的服务器，扩展也不包含广告或分析 SDK。

卡片保存在哪里？

保存在浏览器本地的 IndexedDB（数据库名 starscard-library）。它不会自动同步到其他设备；换电脑前建议在卡片库导出 ZIP 备份。

为什么有些长图不是 3 倍？

浏览器画布有尺寸上限。普通卡片会优先用 3 倍；长文依次尝试 2 倍、1.5 倍。仍超出安全尺寸时会停止绘图，但完整原文会保留，可以复制文字或换版式重试。

支持 Edge、Arc 这些浏览器吗？

支持基于 Chromium 的浏览器，包括 Edge、Arc、Brave 等。安装方式与 Chrome 相同，在对应浏览器的扩展商店中安装或加载 Chrome Web Store 版本。

换版式后，之前的图片会变吗？

预览会立即重绘；复制、下载和自动保存都会使用当前版式。已经保存的低分辨率旧卡片不会自动重制，需要回到原文重新生成。
