一句话版本

摘录、页面信息、卡片与设置默认在本机处理，不会自动上传。若你主动发送支持邮件，开发者会收到邮件地址、问题描述及随附的诊断信息；扩展不包含广告或分析 SDK，也没有账号系统。

01我们处理哪些信息

摘星卡片的 Chrome v1.6 与 macOS Safari v1.6.1 版本会在本机处理以下信息，以生成和管理网页摘录卡片：

  • 你主动选中的网页文本。
  • 当前网页的标题、域名或链接，用于生成来源信息和原文二维码。
  • 你选择的卡片版式、扩展开关、自动保存开关等偏好设置。
  • 你在本地卡片库中保存的卡片文字、图片、批注和标签。
  • 你主动导出或导入的备份文件。备份文件由你选择保存位置。

如果你主动通过邮件联系开发者并选择发送，开发者会收到该邮件的发件邮箱地址、问题描述和随附内容。Safari v1.6.1 的反馈报告还可能包括最近错误记录、浏览器标识、平台、语言、反馈页地址和扩展版本；某些图片生成错误记录可能包括出错网页的域名与路径，不包含查询参数或链接片段。正常的摘录文字、卡片图片、批注和标签不会自动加入 Safari 反馈报告。

02信息如何使用

本地处理的信息用于生成和保存摘录卡片、复制卡片图片或文字、下载 PNG、保存偏好设置，以及让扩展在当前页面正常工作。反馈邮件中的问题描述和诊断信息用于回应支持请求与定位故障；邮件地址与该次反馈关联，不用于广告或跨应用、网站追踪。

扩展不会自动上传摘录内容、卡片或浏览历史，也不会将反馈信息用于广告投放、用户画像、数据交易或与支持和故障定位无关的用途。

03数据存储与传输

Chrome 与 Safari 的偏好设置保存在各自的浏览器扩展本地存储中；卡片与图片保存在浏览器本机的 IndexedDB 数据库 starscard-library 中。扩展没有账号或自动跨设备同步。

卡片功能不包含云端同步或远程代码，不会自动向开发者服务器上传摘录、卡片或浏览记录。错误日志平时保存在本地扩展存储中。

Safari v1.6.1 的反馈页可供你查看、复制或导出本地错误日志。发起反馈时，扩展会打开你选择的邮件服务并预填邮件草稿，不会自动发送。邮件服务商会处理该邮件；只有你在邮件客户端中选择发送后，开发者才会收到邮件内容。你可以检查或修改草稿、选择发送，或关闭草稿而不发送。

清除本地错误日志不会删除已经发送的邮件，也不会撤回邮件服务商或开发者已收到的副本。如需查询或提出删除已发送反馈的请求，请通过本页下方的联系方式联系开发者。

04权限说明

Chrome v1.6 使用以下权限完成扩展功能：

  • storage：保存扩展开关、版式选择和自动保存偏好。
  • clipboardWrite：把生成的卡片图片或摘录文字复制到剪贴板。
  • scripting：在当前页面注入必要的界面与脚本，确保安装或更新后无需刷新页面也能工作。
  • 主机权限 http://*/* 与 https://*/*：用于在普通网页上划词生成卡片。

Chrome v1.6 不申请 tabs、downloads 或 <all_urls> 权限。macOS Safari v1.6.1 使用上述 storage、clipboardWrite、scripting 与 HTTP/HTTPS 网站访问权限，并额外使用 activeTab，仅在你主动操作时访问当前标签页。你可以在 Safari 设置里调整网站访问授权范围。扩展只在你主动选中文字后读取当前页面选区，不访问浏览器历史记录清单或下载记录；图片下载通过浏览器本地生成的临时链接完成。

05本地卡片库与备份

自动保存开启时，生成的卡片会写入本机 IndexedDB。你可以在扩展弹窗中关闭自动保存，也可以在卡片库中删除单张卡片或清空全部卡片。

导出备份时，扩展会把卡片元数据与图片打包为 ZIP 文件，保存到你选择的位置。导入时会逐张校验图片和字段，并对重复卡片去重；导入过程不会把文件上传到网络。

清除浏览器站点数据、卸载扩展或使用不同的浏览器用户配置，可能导致本地卡片库不可用。建议在更新或迁移前先导出备份。

06第三方共享

扩展不出售或用于广告交易你的数据，也不包含第三方广告 SDK 或分析服务。你主动发送支持邮件时，邮件会经你选择的邮件服务商传递给开发者；扩展不会在未经你操作时把摘录或卡片交给第三方。

Chrome 版通过 Chrome Web Store 分发；macOS Safari 版通过 Apple 的分发渠道提供。你与 Google、Apple 之间的商店或服务交互，分别适用其隐私政策。点击卡片上的原文二维码或链接时，你访问的是原网页，适用该网站自己的隐私政策。

07儿童隐私

摘星卡片不是专为儿童设计的产品。卡片功能主要在本机处理信息；如果儿童或监护人主动发送支持邮件，开发者可能会收到邮件地址、问题描述及随附诊断信息。我们不会有意通过扩展主动收集儿童个人信息。

08政策更新

如果未来扩展的数据处理方式发生实质变化，例如加入云端同步或新的网络请求，我们会更新本页面，并在必要时通过扩展说明或发布记录告知用户。

当前说明对应 Chrome v1.6（内部版本 1.60.0）与 macOS Safari v1.6.1。历史版本的隐私说明可在 GitHub 仓库的提交记录中查看。
