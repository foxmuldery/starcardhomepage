一句话版本

摘录内容、页面信息和生成的卡片都在你的浏览器里处理。开发者没有接收这些内容的服务器；扩展不包含广告或分析 SDK，也没有账号系统。

01我们处理哪些信息

摘星卡片是一款把网页摘录生成分享卡片的 Chrome 扩展。为了完成这个功能，扩展会在你的浏览器本地处理以下信息：

  • 你主动选中的网页文本。
  • 当前网页的标题、域名或链接，用于生成来源信息和原文二维码。
  • 你选择的卡片版式、扩展开关、自动保存开关等偏好设置。
  • 你在本地卡片库中保存的卡片文字、图片、批注和标签。
  • 你主动导出或导入的备份文件。备份文件由你选择保存位置。

02信息如何使用

这些信息只用于：在本地生成摘录卡片、把卡片图片或文字复制到剪贴板、下载 PNG、保存你的偏好，以及让扩展在当前页面正常工作。

摘星卡片不会把你的摘录内容发送到开发者服务器，也不会用于广告投放、用户画像、数据交易或与核心功能无关的用途。

03数据存储与传输

偏好设置保存在 Chrome 提供的本地存储中。卡片与图片保存在浏览器本地的 IndexedDB 数据库 starscard-library 中，不会自动同步到其他设备。

v1.6 不包含云端同步、账号登录或远程代码。扩展不会主动建立开发者服务器连接来上传你的摘录、浏览记录或个人资料。

如果你通过邮件联系开发者，邮件内容会由你的邮件服务商处理，这不属于扩展本身的自动数据收集行为。

04权限说明

v1.6 的 manifest.json 只申请以下权限：

  • storage：保存扩展开关、版式选择和自动保存偏好。
  • clipboardWrite：把生成的卡片图片或摘录文字复制到剪贴板。
  • scripting：在当前页面注入必要的界面与脚本，确保安装或更新后无需刷新页面也能工作。
  • 主机权限 http://*/* 与 https://*/*：让你可以在普通网页上划词生成卡片。扩展会在普通网页注入划词脚本，但只在你主动选中文字后读取选区内容，也不会读取浏览历史。

扩展不申请 tabs、downloads 或 <all_urls> 权限。下载图片通过浏览器本地生成的临时链接完成，不读取你的下载记录。

05本地卡片库与备份

自动保存开启时，生成的卡片会写入本机 IndexedDB。你可以在扩展弹窗中关闭自动保存，也可以在卡片库中删除单张卡片或清空全部卡片。

导出备份时，扩展会把卡片元数据与图片打包为 ZIP 文件，保存到你选择的位置。导入时会逐张校验图片和字段，并对重复卡片去重；导入过程不会把文件上传到网络。

清除浏览器站点数据、卸载扩展或使用不同的浏览器用户配置，可能导致本地卡片库不可用。建议在更新或迁移前先导出备份。

06第三方共享

摘星卡片不会出售、出租、转让或共享你的个人数据。扩展不包含第三方广告 SDK，也不会把摘录内容交给第三方分析服务。

扩展通过 Chrome Web Store 分发；你与 Chrome Web Store 之间的交互受 Google 的隐私政策约束。点击卡片上的原文二维码或链接时，你访问的是原网页，适用该网站自己的隐私政策。

07儿童隐私

摘星卡片不是面向儿童的产品。我们不会有意收集儿童个人信息；扩展本身也不收集可识别个人身份的信息。

08政策更新

如果未来扩展的数据处理方式发生实质变化，例如加入云端同步或新的网络请求，我们会更新本页面，并在必要时通过扩展说明或发布记录告知用户。

当前页面对应 v1.6（内部版本 1.60.0）。历史版本的隐私说明可在 GitHub 仓库的提交记录中查看。
